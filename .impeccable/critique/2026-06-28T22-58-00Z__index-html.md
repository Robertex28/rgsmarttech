## Anti-Patterns Verdict

YES — looks AI-generated. Fails both first and second-order slop tests.

First-order: tech services company → dark mode + cyan/blue gradient. Exact category-to-palette reflex.
Second-order: "Not SaaS startup" → still dark + glowing accents + glassmorphism. Same aesthetic family, one layer deeper.

Active violations:
1. Gradient text (background-clip: text) on em (h1, h2), .hero-sub, .stat-n, .why-n — 5 instances
2. Hero-metric template — 4 gradient-number stats (20+, 6, 100%, 2h)
3. Identical card grid — 6 service cards with emoji icon + heading + text + pill tags
4. Eyebrow .tag chip above all 5 sections + .hero-badge on hero
5. Numbered 01/02/03/04 markers in .why-n
6. Glassmorphism on ~15 elements (nav, service cards, why cards, contact cards, cover box, footer socials)
7. JetBrains Mono on numerals — monospace as lazy shorthand for technical

Detector (5 findings): Inter overused font (L19, L41), layout animation transition:width (L462), numbered markers 01-04, dark glow on WA button. All confirmed, 0 false positives.

## Overall Impression

The content is excellent — specific, honest, conversion-focused copy with a real photo. But it's dressed in clothes that say the opposite: a SaaS template that reads as impersonal and generic. The design is actively hiding Roberto's 20-year local credibility behind generic visual noise.

## What's Working

1. Copy is specific and credible. "Te decimos exactamente que tiene tu equipo antes de cobrar" is a real differentiator.
2. Roberto's photo in "Sobre el tecnico" builds genuine trust.
3. WhatsApp conversion architecture: multiple touchpoints (hero, about, contact, float) pointing to the same action.

## Priority Issues

[P0] Reveal animations gate content visibility — .reveal { opacity: 0 } means content is invisible until JS runs. Slow connections or headless renderers see blank sections. Fix: make content visible by default, use animation as enhancement.

[P0] Design IS the anti-reference — dark #0a0a0f + cyan + blue + glassmorphism = exact SaaS startup aesthetic the user rejected as anti-reference #1. Full brand direction change needed. Fix: /impeccable craft

[P1] Gradient text x5 — absolute ban. On em (h1/h2 throughout), .hero-sub, .stat-n, .why-n. Fix: solid white or single accent color.

[P1] Eyebrow chips on every section (5/5) + numbered 01-04 markers — both absolute bans. Fix: remove numbered markers; remove 4 of 5 eyebrows.

[P1] Hero-metric stats — absolute ban. "6 areas de servicio" adds no info over the services section. Fix: remove block, weave "20 anos" into copy.

[P1] Glassmorphism everywhere — ~15 elements. Fix: keep on nav only (appropriate for fixed overlay), remove from all cards.

[P2] Video preload="auto" on 9MB file — burns mobile data immediately. Fix: preload="none" + poster attribute.

[P2] No prefers-reduced-motion support — WCAG 2.1 AA requirement. Fix: add media query disabling all animations.

[P3] transition:width on hamburger spans — layout thrash. Use transform instead.
[P3] Footer social emoji links have no accessible label.
[P3] form-btn missing focus-visible style.
[P3] Phone pattern regex too strict — rejects +58 prefix.
[P3] No autocomplete attributes on form fields.
